# Rimba Pulih – Blog Kampanye Karhutla

Blog satu halaman tentang kebakaran hutan dan lahan (karhutla) di Indonesia 2026, untuk tugas
mata kuliah **Aplikasi dan Teknologi** (Environmental Campaign). HTML, CSS, dan JavaScript murni.

## File

```
index.html
style.css
script.js
README.md
```

## Deploy ke GitHub Pages

1. Buat repository **Public** baru di GitHub (misalnya `rimba-pulih`).
2. **Add file, Upload files**, seret `index.html`, `style.css`, `script.js`, lalu **Commit changes**.
3. **Settings, Pages**: Source **Deploy from a branch**, branch `main`, folder `/(root)`, lalu Save.
4. Tunggu 1 sampai 2 menit. Blog terbuka di `https://USERNAME.github.io/rimba-pulih/`.

## Sebelum dikumpulkan

- Tambahkan nama penulis atau kelompok di bagian `<div class="foot">` pada `index.html`.
- Angka karhutla berubah cepat. Cek ulang sumber di bagian "Sumber data" dan perbarui bila perlu.
- Font (Fraunces dan Figtree) dimuat dari Google Fonts, jadi perlu internet saat dibuka.
